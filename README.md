# FusionVC

**个人学习与方法实践：单细胞扰动预测中的基础模型表示、融合、MMD与知识蒸馏。**

[English](README.en.md) · [详细实验总览](docs/experiment-overview.md) · [最终测试](results/final-test/README.md) · [复现说明](docs/reproduce.md)

这个项目用于学习如何把公开数据、模型适配、对照实验、评价和推理交付串成完整流程。
工作重点是已有方法的实现、组合与验证，不把这些组合本身作为已证明的方法创新，也不以领先排行榜成绩为目标。
作者署名：[xifengke](https://github.com/xifengke)。

任务限定于VCC2025的H1 hESC单基因CRISPRi：给定对照细胞和靶点基因，预测扰动后表达，保留全部18,080个输出基因。
已完成七架构×三损失×三种子共63组验证，另有3个蒸馏Student；在访问测试表达前冻结清单，完成27个checkpoint和一次无扰动对照的本地离线测试评分。
评分使用固定版本的官方工具，这不等同于官方榜单提交、第三方认证或独立外部复现。

## 做了什么

| 部分 | 内容 |
| --- | --- |
| 基线 | MLP；从随机初始化开始训练的Transformer |
| 冻结表示 | scGPT whole-human、Geneformer V1-10M；编码器完全冻结 |
| 三种融合 | Concat、随靶点变化的Gated Fusion、双向基因原型Cross-Attention |
| 三种损失 | 无配对均值MSE、Energy MMD、均值MSE + 0.1 × Energy MMD |
| 知识蒸馏 | 固定融合Teacher，仅对150个训练靶点生成软标签，训练原架构MLP |
| 工程与评价 | 逐靶点成绩、原生实现核对、来源与复现检查、独立Student演示 |

```mermaid
flowchart LR
    A[训练对照与150个训练靶点] --> B[基线 / 冻结表示 / 三种融合]
    B --> C[三种损失 × 三个种子]
    C --> D[50个验证靶点选择与早停]
    D --> E[固定融合Teacher]
    E --> F[仅训练靶点蒸馏MLP]
    D --> G[冻结最终测试清单]
    F --> G
    G --> H[100个未见靶点本地测试]
```

训练、验证、测试分别为150、50、100个互斥扰动靶点；各文件含对照，不能把细胞数相加后视为完全独立样本。
种子固定42/43/44，不挑选测试最好的种子。不同架构的容量、输入粒度及预训练信息不同，当前比较不能独立隔离这些因素。

## 最终结果

MAE衡量整体表达误差，越低越好；PDS衡量扰动区分，DES衡量差异表达基因恢复，后二者越高越好。
下表为模型三种子均值；标准差、各自验证选中的损失和区间见[完整测试报告](results/final-test/README.md)。

| 方案 | MAE ↓ | PDS ↑ | DES ↑ |
| --- | ---: | ---: | ---: |
| 无扰动对照 | **0.026342** | 0.509600 | 0.000189 |
| MLP | 0.026853 | 0.511533 | 0.112435 |
| Transformer | 0.031355 | 0.510033 | **0.169593** |
| 冻结scGPT | 0.026664 | **0.514233** | 0.117656 |
| 冻结Geneformer | 0.026587 | 0.512000 | 0.109469 |
| Concat | 0.026487 | 0.510200 | 0.109815 |
| Gated Fusion | 0.026492 | 0.511700 | 0.110926 |
| Cross-Attention | **0.026463** | 0.512367 | 0.113918 |
| 蒸馏MLP | 0.026509 | 0.511933 | 0.114757 |

**八组神经模型的平均MAE均高于无扰动对照，DES均高于该对照。** 当前结果体现不同指标间的取舍，不支持全面性能提升。
主表按相同候选预算为每架构选择损失，比较的是最终方案，不是严格的纯架构消融。

蒸馏单独与原MLP mean比较，而不是主表中的MLP energy：测试MAE从0.026957降至0.026509，改善约**1.66%**；100个靶点中87个的种子平均MAE更低。
PDS基本持平，DES从0.121207降至0.114757。Student的MAE仍高于实际Teacher和无扰动对照，不称为无损迁移。

## 资源条件与测试集的真实使用情况

全量实验在Windows、Python3.12、PyTorch2.8.0+cu128和RTX4060 Laptop **8GB显存**上完成。
采用冻结编码器、离线特征、有限输入、混合精度、分块读写、磁盘缓存和串行评分控制开销。
这些是实现与预算选择，没有依据写成已发生的系统内存不足或OOM。

**完整测试集已经下载并使用。** 固定版本h5ad约11.95GB，实际170,846个细胞、100个测试扰动、18,080个基因。
真实表达缓存和一个临时预测矩阵各约12.36GB，评分后清理临时预测。
“没有把测试数据提交到源码仓库”与“没有使用测试集”是两回事。
早期记录中的待下载状态描述当时计划，不能当作最终状态。

系统RAM、GPU显存、磁盘和网络是不同限制；最低RAM配置及跨硬件最低要求未测定。
详见[资源与数据说明](docs/resources-and-data.md)。

## 研究边界

这是个人练习、方法对照与工程实践，价值主要在完整实验流程和诚实记录。
范围限于一个数据集、H1 hESC和单基因CRISPRi，没有跨细胞类型、跨数据集、剂量、组合扰动或时间序列验证。
模型学习共同条件位移，异质性主要来自输入对照，尚未学习逐细胞状态依赖响应。
没有新的基础模型预训练、全参数微调、大规模超参数搜索或足以隔离全部混杂因素的消融。

三种子不是三个生物学重复。靶点bootstrap区间仅对当前拟合模型和固定控制抽样成立，未做多重比较校正。
结果不表述为已经确认的生物学机制。进一步边界见[项目定位与局限](docs/project-scope.md)。
