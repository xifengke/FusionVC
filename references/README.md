# Core reading

This source release contains the bibliography README only. PDF and mapping filenames below describe the original local workspace; those files are not bundled here.

1. Roohani et al., Virtual Cell Challenge: Toward a Turing test for the virtual cell. Cell (2025). https://doi.org/10.1016/j.cell.2025.06.008
   The user-provided PDF is copied here as vcc2025.pdf.
2. Cui et al., scGPT: toward building a foundation model for single-cell multi-omics using generative AI. Nature Methods (2024). https://www.nature.com/articles/s41592-024-02201-0
3. Theodoris et al., Transfer learning enables predictions in network biology. Nature (2023). https://www.nature.com/articles/s41586-023-06139-9
   Public author manuscript entry: https://pmc.ncbi.nlm.nih.gov/articles/PMC10949956/

The scGPT author preprint is saved as scgpt-preprint.pdf (57 pages), downloaded from https://www.biorxiv.org/content/10.1101/2023.04.30.538439.full.pdf. It is an author preprint, not the publisher's final PDF. The Geneformer full PDF could not be retrieved from the checked public endpoints; its publisher and author-manuscript links are retained above. Local model and tokenizer details come from official source snapshots in vendor/.

gene_info.csv is the gene identity mapping linked by the official scGPT README; it is a mapping resource, not perturbation supervision.
