# GitHub发布说明

## 项目描述建议

> FusionVC是个人学习与方法实践项目，比较单细胞扰动预测中的基线、冻结基础模型表示、三种融合、MMD和知识蒸馏。项目保留完整对照、负结果、运行条件及复现记录；不以方法原创性或领先排行榜成绩为主要目标。

用具体边界表达定位，无需自称“没有深度或意义”。实现与实验组织有学习价值，但不能代替新方法贡献、外部验证或生物学机制验证。

## 发布内容

保留 `src/`、`scripts/`、`tests/`、`configs/`、`requirements/`、`.github/`、README与文档，
以及 `results/` 中的小型分数、图表、抽样计划和来源收据。
既有科学结果和校验文件保持原内容，不为美化发布而改写历史成绩。

不包含原始数据、模型权重、上游源码快照、论文PDF、虚拟环境、完整checkpoint、表达缓存、日志和临时文件。
本机已验证的Student包不会因为README提及它就自动包含在公开源码内。
下载脚本和来源记录用于重新取得资源，可用性仍依赖上游服务。

本地 `release/` 用于生成源码目录与ZIP，已被忽略，不应把该目录再嵌套提交一份。
原工作区和发布副本分开，可以在保留原始证据的同时检查公开文件范围。

## 读者应清楚看到的事实

- 完整测试集已经下载并用于最终本地评分，没有因未记录的“内存不足”跳过测试。
- 显存、RAM、磁盘与网络是不同限制；分块和缓存有实际记录，未测定的最低配置不作保证。
- 八组神经模型MAE均值未低于无扰动对照；蒸馏改善MAE但降低DES，不能删去这些结果。
- 官方工具的本地评分不等于官方榜单成绩。
- `VERIFIED`仅表示相应内部来源或产物检查，不表示外部独立复现或同行评审。
- 源码检查、带模型包的演示、全量GPU实验和原本机来源核验有不同前提。
- AI工具参与了代码、文档与实验执行辅助；结果按实际产物和运行记录陈述，作者仍需检查发布内容。
