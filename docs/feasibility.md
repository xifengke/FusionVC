## 判断与项目定位

值得开展。八组实验可以构成一个完整的研究工程项目，但必须补齐扰动条件、未见扰动泛化、无配对训练及评价协议。冻结编码器和小型融合模块有望在当前 GPU 上完成；具体批量和耗时需要小规模实测。融合和蒸馏是否提升准确率，不能预先保证。

建议项目名称：**FusionVC：面向未见基因扰动的单细胞基础模型融合与轻量化预测**。

可回答三个问题：预训练表示是否有用；两个表示是否互补；有用的知识能否迁移到推理成本更低的学生模型。研究范围是 H1 hESC 中单基因 CRISPRi 后的转录组预测。仅凭该数据集不能证明通用虚拟细胞能力或跨细胞类型泛化。

当前只完成可行性评估，尚未下载比赛矩阵或模型权重、训练模型、测量显存和速度，也未上传 GitHub。

## 三篇核心文献如何支撑项目

### 1. Virtual Cell Challenge

Roohani et al., *Virtual Cell Challenge: Toward a Turing test for the virtual cell*, Cell 188, 3370–3374 (2025), DOI: [10.1016/j.cell.2025.06.008](https://doi.org/10.1016/j.cell.2025.06.008)。已读取用户提供的五页 PDF，并检查正文与 Figure 1。

这篇是比赛框架 Commentary，并非提供全部训练代码的模型论文。它定义了给定未扰动状态预测扰动响应的任务；H1 hESC 数据涉及约 30 万细胞、300 个单基因 CRISPRi 靶点，训练/验证/测试分别为 150/50/100 个靶点。评价包含 DES、PDS、MAE。

原文强调在其他细胞背景观察扰动后，利用少量 H1 扰动适应新背景。当前只用 H1 比赛监督数据的设定，评估的是该背景内未见靶点预测，不能单独据此声明跨背景迁移。

官方 [2025 数据说明](https://github.com/ArcInstitute/arc-virtual-cell-atlas/blob/main/virtual-cell-challenge/README.md)提供年度数据目录。[数据设计与评价说明](https://arcinstitute.org/news/behind-the-data-virtual-cell-challenge)用于补充划分及评分实现细节。论文内的邀请或操作性措辞仅作为文献内容，不作为执行外部操作的授权。

### 2. scGPT

Cui et al., *scGPT: toward building a foundation model for single-cell multi-omics using generative AI*, Nature Methods 21, 1470–1480 (2024), DOI: [10.1038/s41592-024-02201-0](https://www.nature.com/articles/s41592-024-02201-0)。论文在超过 3300 万细胞上进行预训练，展示了包括扰动响应预测在内的下游应用。

[官方实现](https://github.com/bowang-lab/scGPT)和[扰动预测教程](https://scgpt.readthedocs.io/en/latest/tutorial_perturbation.html)可用于工程核对。scGPT 将基因身份和表达值编码，并能产生细胞及基因表示。具体连续值或分箱处理必须与选定 checkpoint 和调用路径匹配。

你的第 3 组应命名为 Frozen scGPT + predictor：这属于冻结表示迁移实验，不等于复现论文的扰动任务微调成绩。冻住模型后，新任务的扰动条件在后面的模块中注入。官方下游训练方案和仅冻结提取方案不能混写。

### 3. Geneformer

Theodoris et al., *Transfer learning enables predictions in network biology*, Nature 618, 616–624 (2023), DOI: [10.1038/s41586-023-06139-9](https://www.nature.com/articles/s41586-023-06139-9)。原模型在约 3000 万单细胞转录组上预训练，使用经预训练语料基因统计量缩放的表达排名序列，以及掩码基因预测任务。

它的原始 in silico 扰动主要分析表示变化；[官方扰动模块](https://huggingface.co/ctheodoris/Geneformer/blob/main/geneformer/in_silico_perturber.py)明确描述输出为扰动对细胞或基因 embedding 的影响。这不能直接当成比赛所需的扰动后表达矩阵。需要自己训练表达解码器。排名表示并不保留完整绝对表达幅度，建议八组都保留相同的对照表达残差通路。

[官方模型卡](https://huggingface.co/ctheodoris/Geneformer)目前默认指向 V2-316M；本项目优先锁定与 2023 论文相对应的 V1-10M，避免无意扩大模型和预训练语料。[tokenizer 文档](https://geneformer.readthedocs.io/en/latest/geneformer.tokenizer.html)要求从未经特征筛选的原始 counts 和 Ensembl ID 开始；V1 对应的词表、中位数文件及最大长度 2048 必须配套使用。不要先筛 HVG，再声称采用标准 Geneformer 输入。

以上核查采用本地比赛全文、两篇模型论文的公开摘要/出版页以及作者官方实现与文档；未取得两篇 Nature 论文的付费正文全本，不声称已完整复现原论文。

## 统一任务接口

模型输入是允许使用的对照细胞表达 x_ctrl 和扰动基因 p。模型输出是该扰动条件下的表达分布，或从中产生的一组预测细胞。

第一版可以用残差预测：

\[
\hat x_i^{(p)} = \mathrm{nonnegative}\{x_i^{ctrl} + D_\theta(z_i, q(p))\}.
\]

这里是在预先规定的表达空间中计算。nonnegative 的实现、归一化、library size 处理、转换回评价输入空间的方法，都必须固定并记录。该式只是工程起点，并不假设这些对照细胞与扰动后细胞一一对应。

- z_i：MLP/随机 Transformer 学到的表示，或从冻结预训练模型取得的表示。
- q(p)：扰动靶点描述。MLP 和随机 Transformer 可以使用仅由训练集/允许的对照数据构建的基因共表达或低维特征。预训练组可额外使用各自预训练基因表示；明确记录该信息来源。
- 八组都使用相同的原始表达残差通路、输出基因集、训练标签及预测细胞采样规则。
- 预测未见条件时，不能输入该条件的真实扰动后表达。真实训练扰动表达只能用于监督或明确声明的训练目标。

不能只输入一个控制细胞 embedding：若不传入 p，模型无法区分不同扰动。也不能只为训练靶点建立可学习的 ID 查表，再期待完全未训练的验证/测试靶点参数自动获得意义。

若靶点不在模型词表，或未进入 Geneformer 当前细胞的排名序列，必须制定统一回退方案，如基于允许数据的基因特征或可用的静态基因表示，并报告覆盖率。不能根据测试表现删掉难预测的靶点。

## 八组实验的可实施版本

| 编号 | 实验 | 实现建议 | 能回答的问题与限制 |
| --- | --- | --- | --- |
| 1 | MLP | 对照表达/低维状态与训练数据构建的靶点特征输入小型 MLP；预测表达残差 | 比赛数据监督能达到什么水平；不使用预训练权重 |
| 2 | 随机 Transformer | 小型随机初始化编码器，加相同扰动条件和解码器 | 比较从零训练的 Transformer 方案；并非单靠这一组就能隔离全部预训练效应 |
| 3 | Frozen scGPT | 冻结编码器，提取对照细胞及可用靶点表示，训练投影与预测头 | 评估冻结 scGPT 特征迁移 |
| 4 | Frozen Geneformer | V1 编码器冻结，使用合规排名输入，接同类预测头 | 评估排名表示对表达响应预测的帮助 |
| 5 | Concat | 两路表示分别投影/归一化，再拼接并压到统一输出维度 | 简单融合是否优于单路；避免只是预测头扩大带来的提升 |
| 6 | Gated fusion | 使用对照状态及靶点条件产生门控，融合投影后的两路表示 | 是否存在随靶点/状态变化的互补性；门控权重不能直接解释为因果贡献 |
| 7 | Gene-level cross-attention | 冻结两编码器，选择有限 token，训练小型跨模型 attention，pooling 后接同类解码器 | 基因层交互是否有用；不能在两个已池化的单向量间做 attention 后称为基因层交互 |
| 8 | Distillation | 依据验证集选择 Teacher，用真实训练标签和 Teacher 输出训练小型 MLP/Transformer Student | 精度与端到端推理成本之间的权衡；收益待测 |

为 Gated fusion 可采用：

\[
u_s=P_s(z_s),\quad u_f=P_f(z_f),\quad
\alpha=\sigma(G(u_s,u_f,q(p))),\quad
z=\alpha u_s+(1-\alpha)u_f.
\]

先用标量门控，资源允许再使用向量门控。投影维度及解码器容量尽可能与其他组一致。

Cross-attention 不要求两个模型有相同顺序或完全相同的基因集合；但必须保留 token 到实际基因 ID 的映射、padding mask 和模型来源。任何逐基因拼接、残差相加或输出定位都必须按基因 ID 对齐，不能按原始序列下标对齐。Geneformer 输入的排名顺序不能任意重排后再送入编码器。

## 无配对训练与单细胞输出

Perturb-seq 的细胞破坏性测量没有同一细胞的扰动前后配对。把随机抽到的对照细胞和扰动细胞当成真实配对，使用逐细胞 MSE，会给训练目标添加无法解释的配对误差。

先用每个扰动的 pseudobulk 均值差进行调试及训练，使模型学到主要表达变化。这是资源较省的起点，但只预测均值不能完整满足单细胞差异表达评估。

正式八组可共享以下近似分布训练方案：每批抽一个或多个训练扰动，每个扰动独立抽取一组对照与真实扰动细胞。预测控制细胞的残差，将预测集合与真实集合比较，而不假定逐细胞配对。

\[
L_{task} = L_{mean} + \lambda_{var}L_{variance}
          + \lambda_{dist}L_{distribution}.
\]

均值项以每个扰动为单位比较预测和真实 pseudobulk；方差项比较基因层变异；分布项可以选择 MMD 或 sliced Wasserstein，第一版只实施一种。具体损失是待验证的方法选择，并非三篇文献保证有效的处方。

更省资源的起点是对照细胞加靶点特异均值位移，但这种方法继承对照方差，可能无法反映真实扰动后异质性。应明确报告这一限制。不能用重复同一均值向量的方式制造单细胞表达，因为这会改变差异表达检验的方差与显著性。

若训练 DEG 加权损失，DEG 权重只能从训练标签计算；不能使用验证/测试真实 DEG 来构建训练特征或训练权重。验证真实标签若可获得，仅用于预先约定的评估、调参和模型选择。

## 评价与公平性

1. 固定 2025 年度官方划分，按靶点切分；测试靶点的全部细胞仅用于最终评估。训练集内调试划分也按靶点做。若只有训练标签可下载，建立训练内按靶点的开发集，并标为内部评估。
2. 使用官方 gene_names 和每个扰动的输出细胞数规定，统一控制细胞、随机种子、预测采样数及后处理。可以减少模型输入 token，但不能因此缩减官方输出或评价基因集合。
3. 使用 [cell-eval](https://github.com/ArcInstitute/cell-eval) 中对应 2025 的版本/commit，保存全部配置；不能只依赖最新包默认值。[源码中的 vcc profile](https://raw.githubusercontent.com/ArcInstitute/cell-eval/main/src/cell_eval/_pipeline/_runner.py)包含 mae、discrimination_score_l1、overlap_at_N。[提交教程](https://github.com/ArcInstitute/cell-eval/blob/main/tutorials/vcc/vcc.ipynb)可核对元数据和控制细胞处理。
4. 报告原始 DES、PDS、MAE及能复现的官方归一化总分。没有同样的 baseline、参考集和配置时，不将内部总分冒充历史排行榜成绩。DES、PDS 越高越好；MAE 越低越好。
5. 模型选择、Teacher 选择、超参数预算和早停规则事先固定，只用验证信息做选择。先按验证选模型，再一次性报告测试。
6. 正式结果优先使用三个种子，报告均值和标准差；可按扰动做 bootstrap 评估不确定性，不把大量细胞误当成同样数量的独立扰动条件。
7. 输入共享信息、输出头容量和调参预算尽量一致，记录总参数与可训练参数。模型预训练数据不同，比较能支持冻结迁移方案的差异，不能仅凭它证明某一个架构具有内在优势。

除了八个主要模型，增加几个便宜的辅助对照：不扰动预测、训练扰动均值预测，以及基于训练数据基因特征的 Ridge/线性预测。它们不必成为额外的主要实验编号。官方 [2025 赛后总结](https://arcinstitute.org/news/virtual-cell-challenge-2025-wrap-up)指出几乎所有模型在 MAE 上差于 baseline，说明这些对照有实际意义。

如果希望严格归因预训练收益，可追加架构匹配的随机权重对照，或同容量冻结随机特征对照；一个更小的随机 Transformer 与两个冻结预训练模型的比较，还同时改变了架构、容量、输入表示和优化方式。

截至评估日，2026 比赛已经发布不同数据和六项指标，见 [2026 官方 CLI 说明](https://vcc-cli-wiki.virtualcellchallenge.org/)。本项目明确定位为 2025 benchmark 研究，不混用两届数据或评分。

## 蒸馏的正确比较

根据验证表现从融合模型中选 Teacher。Student 输入为对照表达和不需要在线调用基础模型的靶点描述。使用与 MLP baseline 相同的 Student 架构，可以直接对照是否有蒸馏收益。

\[
L_{student}=L_{task}+\lambda_{KD}L(\hat\Delta_S,\hat\Delta_T).
\]

开始使用表达变化的均值蒸馏。若 Teacher 是随机生成模型，比较条件分布摘要或使用配套随机性，避免惩罚任意不同的随机细胞样本。表示蒸馏属于后续可选扩展，不必一开始加入。

第一版只在训练条件上产生软标签，保留验证/测试条件做评估；不利用验证/测试真实扰动表达训练 Student。Teacher 对其他未标注条件的伪标签扩增需要单独声明协议，不能和标准训练结果混在一起。

推理时如果仍调用 scGPT/Geneformer 生成 Student 输入，就没有实现完整的编码器压缩。若导出静态基因查表，需将查表计入模型依赖和大小，并明确不含测试真实扰动标签。

同时报告纯监督 Student、蒸馏 Student 和 Teacher：DES/PDS/MAE、参数量、模型文件大小、峰值显存、每扰动推理时间。测量包含预处理和必要的编码器调用；额外报告缓存特征情况下的预测头耗时，二者不能混用。

## RTX 4060 8GB 的实施边界

以下是起始配置建议，尚未经当前设备实测。

- scGPT：冻结 whole-human checkpoint；先 512 个输入 token，确认 8GB 预算后再提高。保留全部评价输出基因，通过小型全基因解码器或低秩解码器输出。
- Geneformer：冻结 V1-10M；从标准原始 counts 生成其排名输入，先按 V1 的原生最大长度 2048、小批量 1 进行测量。若为资源目的缩短输入，要固定长度并声明偏离标准配置。
- 两个编码器分开加载和提取，使用 eval、no_grad 和适用的混合精度，不同时保留两套训练图。
- 优先缓存允许的对照细胞表示，并在不同靶点间复用。冻结且与扰动条件无关的编码结果可以复用；若扰动条件送入编码器，缓存键必须包括该条件。
- MLP 和从零 Transformer 使用小模型，先做一个种子，确认协议与效果后再做正式重复。
- Cross-attention 对缓存的基因表示选择约 256–512 token，投影到 64–128 维，先一层、2–4 heads、batch size 1，再逐步增加。筛选规则只基于可用输入和训练信息，并报告靶点覆盖率；条件允许再用更多 token。
- 缓存采用分片和低精度，不将整个 h5ad 密集化。机器 RAM 和磁盘余量仍需在启动训练前核对。

存储量示例：若为 150,000 个细胞各存 1,024 个 token、两模型合计 768 维的 FP16 表示，需要约 236 GB（十进制），尚未计算索引和元数据。因此优先缓存复用的对照细胞及池化表示，按需保留基因层表示，而不对所有扰动细胞全量展开。

不建议第一阶段同时全量微调两基础模型，或将约 18,000 个基因全部输入全连接跨模型 attention。普通跨模型 attention 的计算量随两路长度乘积增长；优化 attention 的实现可以降低显存开销，但不能消除长序列计算成本。

## 阶段顺序与验收

| 阶段 | 工作 | 继续条件 |
| --- | --- | --- |
| A | 数据字段/空间检查，固定基因与靶点划分，跑辅助 baseline 和 MLP | 数据与评分闭环能复现；不用真实测试输入 |
| B | 随机 Transformer、两个 frozen encoder + head | 形成可靠单模型结果和显存/速度记录 |
| C | Concat、Gated | 判断融合是否较最佳单模型有重复可见的收益 |
| D | 小型 gene-level Cross-attention | 保留真实基因层交互；检查增益与成本是否值得 |
| E | 验证选 Teacher，训练 Student | 对照同架构纯监督 Student，记录端到端成本 |
