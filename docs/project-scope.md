# 项目定位、研究边界与结果解读

本项目由个人开展，用于学习单细胞数据处理、基础模型适配、融合、无配对集合损失、蒸馏、评价与复现。
预期产出是可阅读的代码、成体系的对照和如实记录的结果。已有方法的实现与组合不自动构成方法创新。
项目深度应由实际覆盖范围判断，无需笼统地自称“没有意义”，也不把学习项目包装成已获充分验证的研究突破。

## 已经完成的工作

七架构、三种损失、三种子共63次正式验证，以及三个蒸馏 Student；按验证规则冻结后完成27个 checkpoint 和一次无扰动对照的本地测试评分。
对编码器、损失、表达变换和评分适配进行针对性检查，保留逐靶点分数、来源与历史校验记录。
Student 独立包已在本机验证，尚不随源码默认分发。

## 数据与任务范围

- 数据限于 VCC2025 的 H1 hESC 单基因 CRISPRi；训练、验证和测试分别为150、50、100个互斥扰动靶点。
- 这是同一数据背景中的未见靶点预测。没有跨细胞类型、独立数据集、剂量、组合扰动或时间序列验证。
- 各划分含对照，不能把三份文件的细胞数相加后视为完全独立的生物学样本数。
- 原始数据是无配对集合，不存在模型可直接监督的同一细胞扰动前后配对。
- 输出是归一化连续 log1p 表达，不是原始整数 counts。

## 方法限制

模型从靶点描述或冻结表示生成共同表达位移，再施加到不同训练对照细胞。
异质性主要来自对照，尚未实现细胞状态依赖的扰动响应或完整条件分布建模。
Cross-Attention 使用训练对照聚合的基因原型，并非逐细胞在线跨编码器注意力。

scGPT 和 Geneformer 编码器完全冻结，监督训练主要发生在小型预测头上。
此设定不是原论文下游微调结果的直接复现，也没有训练新的基础模型。
不同融合头容量、输入粒度和预训练信息来源不同，目前的对照不能单独隔离融合机制、容量和表示互补的贡献。
没有随机冻结编码器的完整匹配对照、全参数微调对照或大规模系统超参数搜索。

## 选择、评分与统计口径

早停、架构内损失选择和 Teacher 选择均使用验证集，因此验证比较存在选择乐观偏差。
最终测试表达访问前冻结清单，测试未回流训练或超参数调整；测试目标也不生成训练软标签。
各架构按相同三损失预算选取最终方案，这不是严格保持损失相同的纯架构消融。

三种训练种子反映初始化和训练采样波动，不是三个生物学重复。
逐靶点 bootstrap 先平均种子，区间仅对当前拟合模型及固定控制抽样成立，不包含重新进行生物学实验或重新选择模型的全部不确定性。
这些区间未做多重比较校正，单项区间不跨零不等于已证明普遍生物学优越性。

MAE、PDS、DES分别衡量不同方面，附加 Energy MMD 使用固定64+64细胞抽样，不是完整官方排行榜总分。
本项目使用固定版本官方工具进行本地离线评分，未将其表述为官方榜单提交或赛事背书。
结果中 `VERIFIED` 表示相应产物、来源或复现检查通过，不是同行评审、外部独立复现或对科学结论的认证。

## 实际结果应如何描述

八组神经模型的测试 MAE 均值均高于无扰动对照，DES 均高于该对照。
Cross-Attention 的神经模型 MAE 均值最低，Transformer 的 DES 均值最高，scGPT 的 PDS 均值最高。
没有一个方案在全部指标上占优。

蒸馏对照使用相同架构的原 MLP mean。Student 测试 MAE 改善约1.66%，PDS基本持平，DES下降。
其 MAE 仍高于实际 Teacher 和无扰动对照，不能称为全面超越 Teacher 或无损压缩。
Teacher 暖推理同样使用缓存；冻结参数总数之比不能当作实际端到端加速比。

## 尚未完成的研究方向

细胞状态依赖响应、更充分的容量/随机表示消融、跨数据集验证、外部独立复现，以及更系统的统计与资源预算评估。
这些是未来方向，不在当前完成范围内，也不用于解释掉已有负结果。
